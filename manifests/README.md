# Formal manifests

The active manifest surface contains only the formal benchmark protocol:

- `formal/formal-benchmark-v1.json`: sources, materials, methods and tracks;
- `formal/method-registry-v1.json`: adapter result contract and applicability;
- `formal/resource-policy-v1.json`: finite resource tracks and calibration grid;
- `formal/seed-ledger-v1.json`: pilot, formal and deterministic-repeat seeds;
- `schemas/formal-catalog.schema.json` and `schemas/formal-task.schema.json`:
  machine-readable contracts.

The old repository-authored candidate families and development suite were removed
from the active repository. Historical copies are kept outside the active tree.
